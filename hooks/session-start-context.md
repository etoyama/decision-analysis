# decision-analysis

人間に判断を仰ぐ前に、次のどれかに当たるなら `decision-analysis` スキルを読み、
その形式で本文に書いてから聞く。

- 選択肢が2つ以上あり、既存の決定（ADR / AC / 指示 / 原則）から一意に決まらない
- 決定を戻しにくい（公開契約、データ形式、外部に作るもの、ライブラリ選定、名前）
- 効果が今の作業の範囲を超える（ADR の候補）
- 人間が判断の理由を聞き返した（= 最初の提示が足りなかった）
- 人間が「DA で」「Decision Analysis で」と頼んだ（= 直前の判断依頼を出し直す）

当たらないなら、推奨を1行で示して先へ進む。
AskUserQuestion の選択肢の説明だけで判断を渡さない。
